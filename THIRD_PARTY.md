# Third-party components, licenses, and citations

TemplateFlow reference images are fetched separately, not bundled. Retain the selected atlas's `LICENSE` and `template_description.json` (authors and references). Cite TemplateFlow and the atlas creators. ANTs is an external dependency for volume resampling and optional affine/SyN normalization; cite ANTs when using these outputs.

FireANTs 1.5.0 is an external dependency for the default GPU affine/Greedy volume normalization. Its source, weights and optional fused extensions are not bundled. Preserve and follow the [upstream FireANTs license](https://github.com/rohitrango/FireANTs/blob/main/LICENSE), its redistribution terms, and the citations in the [upstream documentation](https://github.com/rohitrango/FireANTs). The FastPrep adapter calls its public registration APIs and exports physical pull transforms; it does not claim that FireANTs Greedy and ANTs SyN are numerically equivalent.

The placement components in `vendor/t2_pial/` include adaptations of FreeSurfer 8.2.0 `mris_place_surface`, its distance-field code and triangle predicate, and a CUDA implementation of the T1 signed-gradient smoother. Preserve `FreeSurfer-SLA.txt`, the notices in the source and the FreeSurfer citations; the compiled drivers link against the user's matching FreeSurfer installation. The CPython license for the linked Python runtime is in `Python-LICENSE.txt`. The CUDA runtime/toolkit is governed by NVIDIA's license. No user's FreeSurfer license file is bundled.

The 8.1 Linux placement build links the T1 entry point from FreeSurfer 8.1.0 (f30dfed) and ports the T2 implementation to that ABI.

The hybrid `vendor/topology/` driver uses the FreeSurfer 8.1.0 sphere entry point and native metric helpers, the user's matching fsbindings and a linked CPython runtime. The same FreeSurfer and CPython license texts in `vendor/t2_pial/` and NVIDIA CUDA terms apply. Cite FreeSurfer for the surface reconstruction and repair.

Model weights and auxiliary assets remain bundled with their upstream naming and directory structure. The `dataset_fingerprint.json` required by nnU-Net is model metadata, not a bundle integrity lock. This project adds no content-hash checks, digest fields, or environment lockfiles.
